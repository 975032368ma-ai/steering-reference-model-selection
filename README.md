# Steering Feedback Actuator: Simulation Data and Code

This repository provides the numerical simulation data and
reproducibility code accompanying the manuscript.

## Download

Open Releases → v1.0.0 → Assets and download:
Actuators_Simulation_Data_Code_Formal_20261110.zip

Extract the archive and follow the README.md inside it.

The archive includes simulation records, model inputs,
analysis programs, and file checksums.
Chapter 7 illustrative bench data and programs are excluded.
